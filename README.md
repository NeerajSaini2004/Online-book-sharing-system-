## 🚀 About The Project

Online Book Sharing System is a full-stack web application designed for students to buy and sell second-hand books and academic study materials.

The platform provides a structured marketplace where users can discover academic resources, securely interact with the platform, place orders, and track their purchases.

The project includes separate frontend and backend components and is designed with a scalable MERN-stack architecture.
